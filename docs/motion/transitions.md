# 换周过渡

通过 `transition` Prop 选择内置换周过渡，也可以在运行时动态切换。默认的 `wave` 只为发生变化的课程执行动画，适合作为兼顾信息连续性与性能的通用方案。

| 预设 | 模式 | 行为 | 建议场景 |
| --- | --- | --- | --- |
| `wave`（默认） | `per-cell` | 新课程按列与节次依次进入，未变化课程保持静止，过渡期间保留旧周内容 | 常规课表换周 |
| `slide` | `page` | 整页沿手势方向移动，课程轻量淡入 | 需要明确翻页方向 |
| `cube` | `page (3D)` | 以固定透视旋转整页 | 强调页面层级的展示场景 |
| `zoom` | `layer` | 新旧周在纵深方向交叠缩放 | 需要短促、整体的过渡 |
| `drop` | `per-cell` | 变化课程逐格进入并轻微回弹，稳定课程跳过动画 | 强调本周课程差异 |
| `none` | layer | 直切 | 无障碍 / 截图 |

## `wave` 的实现原则

1. 时间轴、表头和格线保持静止，避免结构性闪烁。
2. 旧周内容保留至新内容覆盖完成，过渡过程不出现空网格。
3. 课程、位置和状态均未变化的单元格跳过动画。
4. 同一重叠组使用统一延迟，避免层叠课程在过渡中短暂穿透。
5. 仅动画化 `opacity` 和 `transform`；手势可在动画期间继续输入并打断当前过渡。
