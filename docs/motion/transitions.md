# 换周过渡

六种内置预设,通过 `transition` prop 切换,运行时可动态更换:

| 预设 | 模式 | 视觉 | 适用 |
| --- | --- | --- | --- |
| `wave`(默认) | per-cell | 波浪覆盖:旧周垫底,新卡按"列为主、节次为辅"的对角线次序扫入;**换周前后视觉不变的格子完全静止**;任何一帧不出现空网格 | 追求无感切换的默认选择 |
| `slide` | page | **真实整页滑动**(经典 PageView 手感),进场课程叠加轻量逐列淡入 | 喜欢明确翻页感 |
| `cube` | page(3D) | **立方体翻页**:几何严格的刚体折面,铰链严丝合缝,透视静态挂载 | 旗舰观感,拉开档次 |
| `zoom` | layer | **深度缩放交叠**(Shared-Axis Z):下一周从深处浮上,旧周冲向镜头;方向绕 1 镜像 | 高级纵深语言,性能最轻 |
| `drop` | per-cell | **逐格重力坠落**+easeOutBack 回弹+确定性抖动;stableSkip 让动画只落在"变化的课"上,兼作换周 diff 高亮 | 物理趣味 + 信息价值 |
| `none` | layer | 直切 | 无障碍 / 截图 |

## 设计原则(wave)

1. **骨架常驻**:时间轴、表头、格线不参与过渡,频闪在结构上不可能发生。
2. **无空帧**:旧周内容保持在下层直到被新内容覆盖,离场滞后进场 60ms,两层始终交叠。
3. **稳定格静止**:同课程、同位置、同"本周/非本周"状态、同角标数的格子跳过动画——波浪只扫过真正变化的格子。
4. **重叠组整组动**:组内统一延迟;被顶卡遮住的成员在顶卡落定后无感挂载,任何时刻不透底。
5. **只动 opacity / transform**,全程合成器路径;动画期间手势不锁,可打断。
