# Core API

`@iyotsuba/schedule-core` 提供与框架无关的课表计算能力，不依赖 Vue、React 或浏览器环境。它适合在状态层、服务层或自定义界面中复用学期规则、冲突计算、主题令牌和动效协议。

## 使用边界

Core 只负责确定性计算和协议校验，不持有界面状态，也不会请求定位权限、写入系统日历或替宿主持久化数据。Vue、React、Web Components 和 Flutter 可以围绕同一份业务模型提供各自的交互层。
