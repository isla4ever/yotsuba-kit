# Core API

`@iyotsuba/schedule-core` 不依赖 Vue、React 或浏览器。它负责学期规则、重叠分组、主题、动效协议、数据交换、提醒、天气和引导状态机；框架组件只消费这些结果。

## 按能力查找

### 学期、冲突与交换

处理中国高校学期周次、单双周、调休、课程冲突、ICS 导出、分享码、提醒和课程资料计算。

[查看学期、冲突与交换 API](/api/term-data)

### 天气、主题与动效

接入天气快照，生成主题 CSS 变量和课程色板，并配置内置或自定义换周过渡。

[查看天气、主题与动效 API](/api/weather-motion)

## 使用边界

Core 只负责确定性的数据计算和协议校验，不持有组件状态，也不会请求定位权限、写入系统日历或替宿主持久化数据。Vue、React、Web Components 和 Flutter 实现可以围绕同一份业务模型提供各自的交互层。
